Getting started

1. Connect to LucidLink

  1. Go to the Settings tab
  2. Enter your LucidLink API Endpoint (e.g., https://api.lucidlink.com/api/v1)
  3. Paste your API Token (Bearer token from admin console)
  4. Click Load Filespaces

2. Create or select a DataStore

A DataStore connects your LucidLink filespace to an S3 bucket.

  1. Select a Filespace from the dropdown
  2. DataStores will load automatically
  3. To create a new DataStore, click + Create new
  4. Fill in the required fields:
    • Name - Unique identifier
    • Bucket - S3 bucket name
    • Region - AWS region (required)
    • Access Key / Secret Key - AWS credentials

3. Browse and import files

  1. Go to the Browser tab
  2. If this is your first time, enter AWS credentials when prompted
  3. Navigate through folders by clicking on them
  4. To import:
    • Import - Import a single file immediately
    • + Queue - Add a folder to the import queue

4. Monitor progress

  1. Go to the Jobs tab to see queued and running imports
  2. Each job shows:
    • Progress bar and percentage
    • Files completed vs total
    • Throughput (entries/second)
  3. Use the Logs tab for detailed activity

DataStore management

View DataStore info

Click the Info button on any DataStore to see its configuration details including bucket, region, and URL expiration settings.

Delete a DataStore

Click the Delete button to remove a DataStore from LucidLink. This will also remove any saved browsing credentials.

Note: Deleting a DataStore does not delete the S3 bucket or its contents.

Saved DataStores

DataStores with saved AWS credentials appear in the "Saved DataStores" section. These credentials are stored locally and allow you to browse the S3 bucket without re-entering them.

Import behavior

File structure

Imported files are placed in LucidLink at: /<bucket-name>/<original-path>

Folder structure is automatically created as needed.

Re-importing files

If you re-run an import on files that already exist in LucidLink, they will be counted as skipped (not errors). This allows you to safely re-run imports without duplicating data.

Parallel processing

Import jobs run in parallel with multiple workers. Files within each job are also processed in batches for maximum throughput.

Troubleshooting

Connection errors

  • CONN_ERR - Cannot reach the API endpoint. Check the URL and network connectivity.
  • TIMEOUT - Request took too long. The API may be overloaded.
  • ERROR_401 - Invalid or expired API token. Get a new token from the admin console.
  • ERROR_403 - Permission denied. Check your API token permissions.

S3 errors

  • Access Denied - AWS credentials don't have permission to access the bucket.
  • NoSuchBucket - The bucket name is incorrect or doesn't exist.
  • InvalidAccessKeyId - The AWS access key is invalid.

Import errors

  • Already exists - File was already imported (counted as skipped).
  • Failed to create folder - Permission issue in LucidLink filespace.
