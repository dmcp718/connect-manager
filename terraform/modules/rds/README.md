# terraform/modules/rds

Self-contained Terraform module that provisions an RDS Postgres 16 instance with:

- TLS-required parameter group (`rds.force_ssl = 1`)
- Encrypted storage (gp3)
- Automated 7-day backups + CloudWatch PostgreSQL logs
- Performance Insights (7-day retention)
- Master password generated by `random_password` and stored in AWS Secrets Manager as JSON

## Inputs

| Name | Type | Default | Description |
|---|---|---|---|
| `name` | `string` | required | Deployment name — used in resource names, tags, and the Secrets Manager path `/connect/<name>/db`. |
| `subnet_ids` | `list(string)` | required | Private subnet IDs for the DB subnet group (must span ≥ 2 AZs). |
| `security_group_ids` | `list(string)` | required | Security group IDs attached to the RDS instance. |
| `db_name` | `string` | `"connect"` | Name of the initial database. |
| `username` | `string` | `"connect"` | Master username. |
| `instance_class` | `string` | `"db.t4g.micro"` | RDS instance class. |
| `allocated_storage` | `number` | `20` | Storage in GiB. |
| `multi_az` | `bool` | `false` | Enable Multi-AZ. Set `true` for production tiers. |
| `engine_version` | `string` | `"16.4"` | Postgres engine version (minor-version pinned). |
| `kms_key_id` | `string` | `""` | KMS key ARN for Secrets Manager encryption. Empty = AWS-managed key (`alias/aws/secretsmanager`). |
| `tags` | `map(string)` | `{}` | Additional tags merged onto all taggable resources. |

## Outputs

| Name | Description |
|---|---|
| `endpoint` | RDS endpoint string (`host:port`). |
| `port` | Database port (always `5432`). |
| `db_name` | Initial database name. |
| `master_secret_arn` | ARN of the Secrets Manager secret containing master credentials. |
| `master_secret_name` | Name of the Secrets Manager secret. |
| `parameter_group_name` | Name of the DB parameter group. |

## Secret format

The secret stored at `/connect/<name>/db` is JSON:

```json
{
  "username": "connect",
  "password": "<generated>",
  "host": "<rds-endpoint-host>",
  "port": 5432,
  "dbname": "connect",
  "url": "postgresql+asyncpg://connect:<password>@<host>:5432/connect"
}
```

## Consuming the secret in Kubernetes (Epic 3.7)

App pods consume `master_secret_arn` via an ESO `ExternalSecret` that maps the JSON fields into a K8s Secret. The Helm chart's ESO `SecretStore` uses the pod's IAM role (EKS Pod Identity) to call `secretsmanager:GetSecretValue` — no static AWS keys are mounted.

```yaml
# Illustrative ExternalSecret (Epic 3.7 — chart-agent)
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: connect-db
spec:
  refreshInterval: 1h
  secretStoreRef:
    name: connect-aws
    kind: SecretStore
  target:
    name: connect-db
  data:
    - secretKey: DATABASE_URL
      remoteRef:
        key: /connect/prod/db     # = master_secret_name output
        property: url
```
